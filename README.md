# Database Operations Dashboard

Standalone browser dashboard for CSV output generated by `scripts/Get-CMSServerReport.ps1`.

## Run

Open `dashboard/index.html` directly in a browser.

Upload the add/drop SQL files in the template inputs before generating scripts:

- `scripts/Generate-ReplicationAddScripts.sql`
- `scripts/Generate-ReplicationDropScripts.sql`

## Data Files

Upload any CSV files produced by `Get-CMSServerReport.ps1`, especially:

- `*_Publications.csv`
- `*_Articles.csv`
- `*_Subscriptions.csv`
- `*_ReplSchedules.csv`
- `*_Distributors.csv`
- `*_ReplicationTopology.csv`
- `*_ServerInventory.csv`
- `*_DatabaseInventory.csv`
- `*_DatabaseInventory_UserDatabases.csv`
- `*_DatabaseInventory_ServerSummary.csv`
- `*_AG_Replicas.csv`
- `*_AG_Databases.csv`
- `*_AG_Listeners.csv`
- `*_CDC_Databases.csv`
- `*_CDC_Tables.csv`
- `*_CDC_Jobs.csv`

## Dashboard Panes

The main view is organized into panes:

- Replication: topology, publications, articles, subscriptions, schedules, distributors
- Server Inventory
- Database Inventory: all databases, user databases, server summary
- Availability Groups: replicas, databases, listeners
- CDC: enabled databases, tracked tables, jobs

## Script Generation

Select articles in the Articles tab, then generate add or drop SQL. The dashboard modifies the existing SQL templates by replacing the `@InputArticles` values and preserving the rest of the script logic for metadata lookup and command generation.
